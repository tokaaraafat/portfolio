# Tokaa Raafat | Portfolio

Static portfolio site (one HTML file, no build step).

## Files
- `index.html`: the whole site (HTML, CSS and JS)
- `Tokaa_Raafat_CV.pdf`: CV linked from the hero and contact sections
- `projects/`: project screenshots (.webp), see `projects/README.txt`

## Deploy on Vercel
1. Put these files at the root of your repository.
2. Push to GitHub. Vercel serves `index.html` automatically.

## Preview locally
Open `index.html` in a browser.
